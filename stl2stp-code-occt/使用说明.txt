STL2STP（STL 转 STEP/IGES 转换器）
====================================

一、运行要求
- Windows 10/11 64 位系统（系统自带组件即可，无需安装任何运行库）
- 无需 OpenCASCADE 或 Visual Studio 环境，全部依赖已在本文件夹内

二、使用方法
1. 双击 stl2stp-code-occt.exe 启动程序；
2. 载入模型（四种方式任选）：
   - 把 .stl / .step / .stp 文件拖入窗口；
   - 点左上角"打开 STL"按钮或菜单"导入STL"选文件；
   - 命令行方式启动：stl2stp-code-occt.exe "模型文件.stl"；
   - 菜单"文件 → 最近的文件"。
3. STL 网格模型：右侧"任务"窗格可查看统计（顶点/边/面/包围盒）、
   网格简化（可撤销）、导出 STEP / IGES（超过 10 万面会弹确认框）；
4. STEP 文件为"纯预览"：直接显示 B-Rep 实体（统计为拓扑计数），
   不可简化、不可导出——导出请载入 STL 网格模型；
5. "视图"菜单可切换标准视图（模型自动居中）与深/浅主题。

三、目录内容
- stl2stp-code-occt.exe   主程序
- TK*.dll                 OpenCASCADE 运行库（勿删）
- mfc140u.dll / MSVCP140.dll / VCRUNTIME140*.dll   界面与运行库（勿删）

四、说明
- 程序设置保存在注册表 HKEY_CURRENT_USER\Software\STL2STP-Code；
- 本文件夹整体拷贝到任意位置均可直接运行；
- 首次载入超大模型（百万面级）约需 1-2 分钟并显示进度，属正常现象。
